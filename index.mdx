Bump is a fast, reliable CLI tool for incrementing semantic version strings. Run it in your terminal or drop it into any CI/CD pipeline. It reads your version file, bumps the component you specify, and optionally writes the result back — no scripts, no sed commands, no surprises.

## How it works

<Steps>
  <Step title="Install bump">
    ```bash
    go install github.com/andreimerlescu/bump@latest
    ```
  </Step>
  <Step title="Check your current version">
    ```bash
    bump -check
    # v1.0.2
    ```
  </Step>
  <Step title="Bump the version">
    ```bash
    bump -patch
    # Bumped v1.0.2 → v1.0.3
    ```
  </Step>
  <Step title="Write it back to the file">
    ```bash
    bump -patch -write
    # Bumped v1.0.2 → v1.0.3 (saved to VERSION)
    ```
  </Step>
</Steps>

## Key features

<CardGroup cols={2}>
  <Card title="Multiple bump types" icon="arrow-up">
    Bump `major`, `minor`, `patch`, `alpha`, `beta`, `rc`, or `preview` — individually or in combination.
  </Card>
  <Card title="Multi-file support" icon="files">
    Works natively with `VERSION`, `package.json`, `go.mod`, `Dockerfile`, `Chart.yaml`, and `pom.xml`.
  </Card>
  <Card title="Safe by default" icon="shield-check">
    Dry-run mode is the default. Changes are only written when you pass `-write`.
  </Card>
  <Card title="Pipeline-friendly" icon="code-branch">
    Returns exit code `0` on success and `1` on error. Supports JSON output with `-json`.
  </Card>
  <Card title="Environment controls" icon="sliders">
    Disable pre-release bump types, set default input files, and auto-write via environment variables.
  </Card>
  <Card title="Go library" icon="golang" href="/library/overview">
    Use the `bump` package directly in your Go programs to parse, compare, and bump versions.
  </Card>
</CardGroup>

<Note>
  Bump is safe to use in automated pipelines. It will exit with a non-zero code on any error, making it straightforward to integrate into Makefiles, GitHub Actions, and shell scripts.
</Note>
